CSSについて

CSS（Cascading Style Sheets）は、ウェブページの見た目を装飾するための言語です。このページでは、プロジェクトで使用されているCSSの情報をご紹介します。

使用しているスタイル

📌 共通スタイル

すべての要素に対して、マージンとパディングをリセットし、ボックスモデルを統一しています。

  • * { margin: 0; padding: 0; box-sizing: border-box; }

📌 ボディスタイル

ページ全体の基本的なスタイルを設定しています。

  • フォント: Arial・ヒラギノ角ゴなど（和文・英文対応）
  • 行間: 1.6
  • 背景色: #f9f9f9（淡いグレー）

📌 ヘッダー

ページの最上部に表示されるヘッダーエリア。

  • 背景色: #2c3e50（濃いスレートグレー）
  • テキスト色: 白
  • ボックスシャドウ付き

📌 ナビゲーション

ページ間の移動用メニューです。

  • フレックスレイアウト使用
  • ホバー時に色が変わる（#3498db）
  • 背景色: #34495e

📌 ボタンスタイル

インタラクティブな要素のスタイルです。

  • デフォルト色: #3498db（ライトブルー）
  • ホバー色: #2980b9（ダークブルー）
  • 角丸: 5px
  • トランジション付きで滑らかに変化

📌 レスポンシブデザイン

モバイルデバイスでも見やすいように、768px以下の画面幅で自動調整されます。

  • ナビゲーションが縦方向に変換
  • フォントサイズが縮小
  • パディングが調整

カラーパレット

色名 カラーコード 用途
ダーク #2c3e50 ヘッダー、フッター
ミディアムダーク #34495e ナビゲーション
ライトブルー #3498db ボタン、アクセント
ダークブルー #2980b9 ホバー時

フォント設定

日本語と英語の両方に対応したフォントスタックを使用しています。

  • Arial
  • ヒラギノ角ゴ Pro
  • メイリオ
  • sans-serif（フォールバック）

オススメの使用方法

HTMLファイルで以下のコードを使用して、このスタイルシートを読み込んでください：

<link rel="stylesheet" href="style.css">
